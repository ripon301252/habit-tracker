# 📌 Habit Tracker App

A simple and modern Habit Tracker web application where users can create habits, set goals, and track their daily progress efficiently.

---

## 🚀 Live Demo
🔗 (https://habit-tracker-ce8037.netlify.app/)

---

## ✨ Features

- ✅ Add, edit, and delete habits
- 📅 Track habits daily, weekly, and monthly
- 🎯 Set goals for each habit
- 📊 Visual progress tracking
- 🔥 Streak tracking system
- 💾 Data stored locally (LocalStorage)

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- HTML5 & CSS3

---

---

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone:  https://github.com/ripon301252/habit-tracker-client.git
           
# Go to project folder
cd habit-tracker-client

# Install dependencies
npm install

# Run the project
npm run dev
